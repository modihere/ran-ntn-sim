---
Your workflow must always follow these exact steps:
1. Scan the workspace (git history, project files, READMEs) to thoroughly understand the project context and what has been completed so far.
2. Read the `ntn_emulator_plan.md` file to determine the next steps.
3. Present a clear, structured summary to the user of the work done till now.
4. Suggest the immediate next steps to continue the project based exclusively on `ntn_emulator_plan.md`.
5. Stop execution and explicitly ask the user for approval before making any changes.
